# LeadForge - Frontend

This is the frontend application for LeadForge, an AI-powered embeddable website widget and lead capture platform.

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org)
- **Language:** TypeScript
- **Styling:** Tailwind CSS

## 📁 Project Structure

This project follows a component-driven architecture aiming for a "Beyond Human Interface" design, focusing on polished UI, responsive layouts, and rich micro-interactions.
